# Интерфейс Flashbox

Панель управляет ESP32-P4 в локальной сети: файлы SD, загрузки/удаление,
фоторамка, состояние платы. Это рабочая админка с русскими текстами.

Для работы над внешним видом и UX используй repo-local
`../.agents/skills/ui-ux-pro-max/SKILL.md` (UI/UX Pro Max).
Конкретные файлы здесь известны: `index.html`, общий интерфейс в `demo.html`,
`photo-tools.js`. Поисковый скрипт установлен в
`../.agents/skills/ui-ux-pro-max/scripts/search.py`; запускай Python3 из корня
репозитория либо указывай абсолютный путь к этой локальной копии.
Рекомендации базы не требуют установки Tailwind, React, GSAP или других
зависимостей и не разрешают менять стек проекта.

- Сохраняй обычные HTML/CSS/JS, DOM id, HTTP-контракт и работающие сценарии.
- Ресурсы должны работать из `/www` платы, без обязательного интернета/CDN.
  Шрифты/иконки при необходимости поставляются локально; поддерживается кириллица.
- Нужны адаптивность, читаемые плотные списки, клавиатура, видимый focus,
  достаточный контраст и уважение prefers-reduced-motion.
- Статусы загрузки/удаления/ошибок видны всё время операции. Успех показывается
  после ответа сервера, без выдуманных процентов и ложного подтверждения.
- `index.html` и общий интерфейс `demo.html` должны оставаться согласованы.
  Веб хранится только на SD; gzip/Flash fallback не собирается. Проверь Node-тесты
  `tests/frontend-*.mjs`; для подготовки JPEG — `tests/photo-tools.mjs`.
- Внешний вид сначала проверяй в локальном браузере на desktop/mobile.
  Прошивка/выкладка на плату — только в рамках задачи пользователя.
